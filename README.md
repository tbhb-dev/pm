# pm

This repository holds tbhb-dev's shared project-management workflows:
reusable GitHub Actions workflows and org-wide scheduled jobs.
A CLI plugin is to come. Licensed under Apache-2.0.

## Contributing

Changes land by pull request into `main`. Pull requests need one approving review,
are squash-merged only, and the `conclusion` check must pass before merge.
Issues and Projects are enabled. Issues cover this repository only. The wiki is off.
